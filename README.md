# conFLOW — Approvals you configure

Static slide deck, English, to click through: what a conFLOW approval can do
now, how each part is configured, and one real case (NIS2 supplier review)
from end to end.

**Live:** https://conflow-story.pages.dev
(Cloudflare Pages · auto-deploy on every push to `main`)

## Contents
- `index.html` — the deck, 48 slides
- `screenshots/` — product screenshots
- `screenshots/nis2/` — screenshots of the NIS2 case, every one from a real run

## Controls
- `←` / `→` or space — next / previous slide
- `O` — overview of all slides
- `F` — full screen
- click a screenshot — enlarge
